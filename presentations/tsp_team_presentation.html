1) Chosen problem

The Traveling Salesman Problem

Given a set of cities linked by roads, start from one city, visit every city exactly once, and minimize the total travel distance.

  • Each city is a node.
  • Each road distance is an edge cost.
  • A valid solution is a tour.
  • The best tour is the one with minimum total distance.

2) Team organization

Three members, democratic organization

We organize the project as a small democratic team: major technical choices are discussed together, while each member owns a clear part of the implementation.

  • No permanent hierarchy; decisions are made by consensus.
  • One rotating coordinator keeps each meeting focused.
  • Code review is shared to keep the project consistent.

Algorithm 2

Genetic algorithm

01PopulationKeep several city orders; score each by its total tour distance.
02SelectionShorter tours are more likely to become parents.
03CrossoverCombine parent orders without visiting a city twice.
04MutationSwap two cities, re-score, and repeat.

Testing plan

How we will evaluate the algorithms

We test

City countsSmall for exact comparison; larger for scalability.
LayoutsRandom, clustered, and road-like cities.
RunsRepeat the stochastic algorithms.

We measure

QualityTour length and gap to exact or best known.
EfficiencyRuntime and memory when relevant.
StabilityVariation in tour length across runs.
